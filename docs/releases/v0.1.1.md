# v0.1.1

Verifier and guard fixes. The rules, the ledger format and the on-chain program are unchanged.

## Changes

- **Rules version in the manifest.** `core-manifest.json` now records `rules`, the commit this
  release was exported from. It is the same value the game server stamps on every ledger entry,
  so the verifier knows which entries it can replay with the code in this repository.
- **Honest summary.** A pass that is not final now says why: entries recorded under other rules,
  anchors still pending, or anchors not read on chain. The `--json` output has a `reasons` array
  with the same information.
- **No dead hints.** For an entry recorded under other rules, the verifier names the release to
  run (the one whose manifest `rules` matches) or `--rules-ref any`, never a commit that does not
  exist in this repository.
- **Guard.** The header line Cargo writes into `Cargo.lock` is accepted, so dependency updates
  pass the guard.

## Verify this release

```sh
git clone https://github.com/Crypto-of-Thrones/core.git && cd core
git checkout v0.1.1
node tools/replay-hunt-test.mjs
node tools/verify/verify.mjs <account> --base https://api-beta.cot.gg --rpc https://api.devnet.solana.com
```

`core-manifest.json` holds the SHA-256 of every file, the `tree` hash of the whole release and
the `rules` commit.
