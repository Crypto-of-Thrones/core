# v0.1.3

Dependency updates. The game rules, the ledger format and the draw derivation are unchanged.

## Changes

- **Program dependency.** `spl-token-2022-interface` moves to 4.0.0, still on the Solana 3.x crates
  that Anchor 1.2.2 uses. The instruction interface (IDL) is identical to v0.1.2. The program
  binary built from this release differs from v0.1.2 because of this update.
- **Test dependencies.** `ed25519-dalek` 3, `rand` 0.10, `solana-clock` 4 and `solana-instruction` 4.
  All 28 unit tests, the compute budget test and the 49 LiteSVM tests pass.
- **CI.** `actions/checkout` 7.0.1, pinned by commit SHA.

## Security advisories

The advisories reported for `curve25519-dalek` 3.2.0, `ed25519-dalek` 1.0.1 and `rand` 0.7.3 reach
only the LiteSVM test harness (`litesvm` 0.18.2, a dev-dependency). None of them is linked into the
program. They will clear when a `litesvm` release drops them.

## Verify this release

```sh
git clone https://github.com/Crypto-of-Thrones/core.git && cd core
git checkout v0.1.3
node tools/replay-hunt-test.mjs
node tools/verify/verify.mjs <account> --base https://api-beta.cot.gg --rpc https://api.devnet.solana.com
```

`core-manifest.json` holds the SHA-256 of every file, the `tree` hash of the whole release and
the `rules` commit.
