# v0.1.0

First public version of the Crypto of Thrones core: the code that decides every draw, every
ledger entry and every on-chain payment rule of the game, published for independent audit.

## Highlights

- **Verifiable draws.** Every random outcome comes from a drand quicknet round named before it
  existed. The beacon's BLS signature is checked locally and the uniforms are derived with
  HMAC-SHA256 under the `cot-draw/v1` domain.
- **Hash-chained ledger.** Each account's entries are chained by SHA-256, grouped into hourly
  Merkle epochs and anchored on Solana.
- **Deterministic rules.** The hunt engine and the rule modules run the same way on the server
  and on your machine. `tools/replay-hunt.mjs` replays a hunt hour from its published input.
- **On-chain program.** `programs/cot_core/` with a reproducible build pinned by image digest.

## Verify this release

```sh
git clone https://github.com/Crypto-of-Thrones/core.git && cd core
git checkout v0.1.0
node tools/replay-hunt-test.mjs
node tools/verify/verify.mjs <account> --base https://api-beta.cot.gg --rpc https://api.devnet.solana.com
```

The command verifies an account of the public beta. See the README for every flag, including
`--mainnet` and `--rules-ref`.

`core-manifest.json` holds the SHA-256 of every file and the `tree` hash of the whole release.
