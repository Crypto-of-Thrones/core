# v0.1.4

The on-chain program as deployed on Solana mainnet-beta, and the game rules of the live game.

## Deployed program

| | |
|---|---|
| Program id (mainnet-beta) | `Cyz7fwhJomMxGtNtj752YcuoSvKASRaYTzrxhHu31FaC` |
| Executable hash (`solana-verify get-program-hash`) | `9051ee392c5fd8ec8b1e83e3af5c55555c1e59fbd75b910cb2f91bd99d4663aa` |
| SHA-256 of `cot_core.so` (627,576 bytes) | `1c8110880a347156f1be0082cdc3a9833c0b1253d52f147d3bd7a7c97f621251` |
| Toolchain | Anchor 1.2.2, Solana 3.1.10, solana-verify 0.5.2 (image pinned by digest) |

`programs/scripts/verifiable-build.sh` on this release produces a `cot_core.so` with exactly the
hashes above, which are the hashes of the program data on chain. The program logic and the IDL are
the same as in v0.1.3; this release adds the mainnet program id and the filled `security.txt`.

## Changes

- **Program.** Mainnet program id in `declare_id!` and `Anchor.toml`; `security.txt` with the
  contact, this repository, the source release and revision, and the audit status ("none yet").
- **Rules.** Token prices and token rewards scaled by `BALANCE.price.factor` and
  `BALANCE.reward.factor`; withdrawal limits; Battle Pass seasons and prices; daily tasks and
  chest; horses; the Squire bench and rest rule; fusion and invite rules.
- **New rule modules.** `web/js/duelsim.js` (Duel) and `web/js/descentsim.js` (Dungeon Descent
  training mode).
- **Verifier.** A draw checked by its drand signature only reports `SIG`. Entries recorded
  before the price and reward factors are replayed with the rules of their time, and the Vigil
  prize is replayed.
- **Documentation.** README: deployed program, audit scope of the program, reproduction steps and
  the mainnet verifier command. SECURITY.md names the deployed program ids.

## Verify this release

```sh
git clone https://github.com/Crypto-of-Thrones/core.git && cd core
git checkout v0.1.4
node tools/replay-hunt-test.mjs
node tools/verify/verify.mjs <account> --mainnet --base https://api.cot.gg \
  --rpc https://api.mainnet-beta.solana.com --program Cyz7fwhJomMxGtNtj752YcuoSvKASRaYTzrxhHu31FaC
cd programs && bash scripts/verifiable-build.sh
solana-verify get-program-hash -u https://api.mainnet-beta.solana.com Cyz7fwhJomMxGtNtj752YcuoSvKASRaYTzrxhHu31FaC
```

`core-manifest.json` holds the SHA-256 of every file, the `tree` hash of the whole release and
the `rules` commit.
